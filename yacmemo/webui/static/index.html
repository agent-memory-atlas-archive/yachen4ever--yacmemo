    确定性审计：hash 对齐 + 规则检测（D1 标题重复 / D2 语义撞车 / D3 悬空链接 / D4 游离文件），即点即出。 深度审查：把注册表、主题卡与审计结果交给配置的 LLM，产出提案报告——只提案，绝不自动执行。

    质量提案（curator）

    编辑 config.toml（用户 [[users]]、embedding 模型、curator LLM 均在此文件）。 保存前自动校验 TOML 与字段并备份原文件；涉及用户、模型、端点的修改需重启服务生效。 新增用户：追加一段 [[users]]（id 仅限字母数字_-，不能是 api/ui/health）后重启；删除用户属危险操作，请 SSH 手工处理。
